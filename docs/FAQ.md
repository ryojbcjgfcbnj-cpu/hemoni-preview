# 常见问题

## 这是桌面宠物还是核查工具

桌宠是统一入口，产品还包含资料管理、核查和回答修订。当前仓库展示这些能力，不包含完整桌面端源码。

## 为什么文件里还有 Hemoni 或和鸣

这是项目的旧名称。当前展示名称统一为「较真一下」，历史路径和配置不应仅为改名而随意修改。

## 社区用了什么数据库

Supabase 托管的 PostgreSQL，业务使用 SQL/PL/pgSQL、RPC、Auth 和行级权限。Token Guard 的本地数据库是 SQLite，文件站还使用 JSON 等文件存储。

## 下载 ZIP 为什么没有安装程序

ZIP 是本网站源文件。安装包需要在 Releases 单独发布，并标明版本和适用平台。

## 页面上的数字是真实运行结果吗

展示页含模拟数据，仅用于演示。它们不是用户规模、核查效果、模型用量或商业收益的实测证明。

## 能完全自动判断金融答案对错吗

核查依赖材料完整性、解析覆盖、字段口径和人工复核。当前专家规则提炼覆盖有限的结构化场景，需要额外案例验证。

## 会自动使用访问者的 API Key 吗

本静态网站没有模型调用流程，不需要填写模型密钥。桌面端的模型调用和社区服务属于另外的运行环境。

## 可以直接用于商业项目吗

仓库尚未声明统一开源许可证，复用前请确认授权。第三方依赖、模型、字体和素材分别受各自许可约束。

## 如何反馈

在 Issues 中选择问题或功能建议模板。请用虚构示例或脱敏材料，写明网站还是桌面端、版本、操作步骤和预期结果。
