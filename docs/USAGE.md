# 使用说明

## 只想看看项目

打开 [在线工作台](https://ryojbcjgfcbnj-cpu.github.io/hemoni-preview/demo.html)，选择示例材料、核查维度和场景，点击「开始核查」，定位证据并记录修订。也可切换「同为75%」案例，体验同值错字段判断。

「较真广场」提供本地求助、讨论、采纳和找行家交互，使用虚构内容，不连接真实社区。内容仅保存到当前浏览器。

保存待复核不会改变正文；在核查记录里可以继续复核。确认应用后，可试跑候选规则。文件站展示关联材料，Token 监控通过点击生成模拟用量。记录保存在当前浏览器，重新体验会清空演示记录。

案例与 Token 数据均为虚构，本地规则只识别预设句式；无法识别时显示待核。不读取 Codex 日志，不调用 AI，不产生模型费用。请勿输入私人材料。

## 想下载桌面软件

先查看仓库 Releases 是否有实际安装包及说明。如果没有可用安装包，可用 Issue 询问发布安排。GitHub 的「Code → Download ZIP」下载的是本网站源码，不是安装包。

桌面端使用自己的模型配置、可选模型下载与社区登录；这些能力不会因为打开演示网页自动准备好。

## 桌面端的典型流程

1. 从桌宠入口或文件站加入材料。
2. 在较真工作台选择原始材料与待查材料，设置关注范围。
3. 查看数字、引用和口径相关候选问题，点击证据并对照原件。
4. 逐项复核，保存核查记录。
5. 需要改稿时，在 AI 回答编辑台选择文字，打开「记录核查修订」。
6. 填写改稿和证据，保存待复核或确认应用；在核查记录中查看历史、补证并导出。
7. 对受支持的字段纠错，可补充指标、适用条件、字段角色及证据时点，提炼候选规则并换案例试跑。

实际入口和可用范围以所运行的桌面版本为准，演示网站不复现完整操作。

## 网站开发者

直接用浏览器打开 index.html 即可查看主体页面。网站是静态文件，不包含 package.json，也没有 npm 启动或构建命令。

修改后检查窄屏布局、导航链接、按钮和浏览器控制台。GitHub Pages 发布方式取决于仓库 Settings → Pages 的实际配置。仓库改名后要验证新网址，并更新文档中的在线演示链接。
