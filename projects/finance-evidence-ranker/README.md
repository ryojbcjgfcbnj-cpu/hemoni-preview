# 金融证据排序

[在线项目展示](https://ryojbcjgfcbnj-cpu.github.io/hemoni-preview/evidence-ranker.html) · [返回较真一下](../../README.md)

从引用替换记录中构造成对训练信号，将采用的证据作为正例、被替换的引用作为难负例，学习区分不同业务口径的材料。公开仓库展示方法、工程实现和汇总结果。

## 数据公开范围

题库不公开。仓库不提供问题原文、候选证据、来源摘录、正确引用、修订标签、逐题分数、预测缓存、模型向量或训练权重。网页不加载题库，不提供逐题回放。

## 方法

线性排序头计算 s(q,e) = w·φ(q,e)，以正负证据的分差构造 softplus 成对损失，加入 L2 正则，通过 SciPy L-BFGS-B 优化。特征包含字符相关度及交互特征，或冻结 CompassJudger-2-7B 提取的问题—证据联合向量。冻结基座，只训练排序头。

普通负例与修订难负例使用相同训练对数。按文档划分训练、验证与留出数据，同源问题不跨划分；验证集选参后另做共用 L2 的对照。

## 汇总结果

人工编写基准共 42 份文档、84 个问题：训练 24 份 / 48 题，验证 6 份 / 12 题，留出 12 份 / 24 题。每种方法使用 96 对训练样本。另有一个公开来源条款单案两题核对，内容不公开。

| 方法 | 留出集首选命中 | MRR |
| --- | ---: | ---: |
| 字符 BM25 | 21/24 | 0.938 |
| 字符排序头：普通 / 修订难负例 | 21/24 → 21/24 | 0.938 → 0.938 |
| 冻结 7B：普通负例 | 17/24 | 0.847 |
| 冻结 7B：修订难负例 | 21/24 | 0.938 |
| 7B 零样本直接选证据 | 23/24 | — |

共用验证选定的 L2 系数 0.002 时，冻结排序头为 18/24 → 21/24。修订难负例对本轮冻结排序头有帮助；BM25 与其持平，零样本命中更多。小样本结果不代表真实业务或跨机构泛化效果。

## 本地使用边界

Python 3.11，依赖版本见 requirements.txt。代码所需题库文件不随仓库提供，不能下载后直接复现原实验。若在本地运行，需自行准备有权使用的数据，并按 dataset.py 的输入协议配置。Node.js 模型调用另需安装 node-llama-cpp 并自行准备合规 GGUF 权重。请勿将私有数据、生成的逐题结果或权重提交到公开仓库。

实验尚未接入桌面产品的自动训练链路。原实验曾使用缓存向量复跑并核对汇总指标，但此处不提供私有缓存。第三方模型与依赖沿用各自许可证；项目授权见仓库根目录说明。
