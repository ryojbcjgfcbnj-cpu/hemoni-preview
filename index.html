技术架构

本地优先，受管调用

Electron 多窗口桌面应用；业务存储以 JSON、原件副本和本地目录为主；模型调用走统一受管路由，每步可记录、可检查。

01统一模型路由

按角色选择 API 或本地模型；受管入口记录用量、发送工作状态、触发完成推送；适配 OpenAI / Anthropic / Google 三种请求格式。

02本地 AI Worker

node-llama-cpp 跑独立子进程，主进程不直接长时推理；SenseVoice 本地语音识别；两个组件互不影响、可单独调度。

03文档解析引擎

mammoth、pdfjs、docx-preview、jszip：Word / PDF / Markdown / 表格统一读取，原件副本与提取正文分开保存、哈希可查。

04隐私分级与受管出口

内容识别为公开 / 内部 / 机密；外发前统一审阅，机密出口拦截，敏感上传可选脱敏副本——面向模型副本，不擦除原件。

05完成判定与轮次账本

只看终态证据 + 延迟防抖，不靠日志沉默猜完成；轮次 token 按身份去重累计，额度快照缓存优先、失败不覆盖已知值。

06双向消息与授权更新

飞书 SDK / 钉钉 Stream 官方连接、扫码绑定、私聊过滤；独立授权服务管激活租约与设备约束，electron-updater 分发更新。
